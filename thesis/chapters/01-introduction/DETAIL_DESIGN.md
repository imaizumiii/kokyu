# 第1章「はじめに」詳細設計

状態：本文初稿を作成し、PDFで確認済み。全章完成後に章構成表と用語を最終調整する。

## 章の役割

本論文で扱う問題、到達点、前提知識、各章の関係を最初に明示する。セミナーで用いた資料と学んだ内容、HHLに関心を持った理由、主題を選んだ理由も示す。HHLアルゴリズムの数学的説明を目的とし、量子計算一般の歴史やハードウェアの概説には広げない。

## この章を読むための前提

- 複素ベクトル空間、内積、固有値・固有ベクトル、ユニタリ行列、エルミート行列など、線形代数の基本事項。
- 量子計算の知識は仮定しない。量子計算固有の記法と公理は第2章から導入する。

## 章を読み終えた時点で明確になっていること

- 本論文が線形方程式 \(A\boldsymbol{x}=\boldsymbol{b}\) とHHLアルゴリズムを扱うこと。
- HHLの出力は解ベクトルの全成分そのものではなく、原則として解に比例する量子状態であること。
- 理想的な正しさ、成功確率、有限精度、計算量を区別して説明すること。
- 本文で既知とする事項と、本文中で定義・証明する事項。
- セミナーで何を学び、なぜHHLを本論文の主題として選んだか。

## 1.1 本論文の目的

### 記述する内容

1. セミナーで`SRC-001`を用いて量子計算の基礎と量子アルゴリズムを学んだこと、およびその中でHHLに関心を持った経緯を述べる。
   - 学んだ内容は、第2〜4章で実際に扱う事項と対応させる。
   - 関心を持った理由と主題選択の理由は、一般論で補わず、執筆者本人の経験と考えに基づいて記す。
2. 古典的な線形方程式
   \[
   A\boldsymbol{x}=\boldsymbol{b}
   \]
   を提示し、多くの計算に現れる基本問題であることを述べる。
3. HHLが扱う量子線形方程式問題では、規格化された入力 \(|b\rangle\) に対し、理想的には
   \[
   |x\rangle
   =\frac{A^{-1}|b\rangle}{\lVert A^{-1}|b\rangle\rVert}
   \]
   を生成することを、後で厳密に定義する予告として示す。
4. 本論文の中心課題を次の三点として明記する。
   - HHLに必要な量子計算の定義と公理を整備する。
   - 各サブルーチンの数学的性質を証明する。
   - 各レジスタの状態変化を追い、成功時に上式の状態が得られることを示す。
5. 理想的な場合の正しさと、有限精度・入力準備・行列指数関数の実行可能性を含む計算量上の条件を分けて論じる方針を示す。

### 本節では証明しないこと

- HHLの正しさは第4章で証明する。本節では問題と到達点だけを述べる。
- 高速化の程度を無条件には主張しない。計算量の評価は入力・行列へのアクセス条件を明示した第4章6節に置く。

### 出典

- HHLの問題設定、構成、および機械学習から線形方程式への導入：`SRC-001`の4.4.1〜4.4.2。
- 主資料で省略されている式変形は、本論文独自の補足として明示する。

## 1.2 本論文の構成と前提知識

### 記述する内容

1. 各章の役割を一段落ずつ説明する。
   - 第2章：量子状態、測定、テンソル積、量子回路、符号化、制御回転。
   - 第3章：量子フーリエ変換、量子位相推定、振幅増幅、行列指数関数。
   - 第4章：量子線形方程式問題、HHLの手順・正しさ・具体例・成功確率・有限精度。
   - 第5章：結果と成立条件の整理。
2. 線形代数の基本は既知とする一方、次の事項は本文で定義することを明記する。
   - ブラケット記法と量子状態。
   - 量子計算の公理。
   - テンソル積とHHLに必要な性質。
   - 量子フーリエ変換、位相推定、振幅増幅。
3. 有限次元の純粋状態と射影測定を対象とすることを明記する。
4. 記号の基本方針を示す。
   - ベクトルは量子状態として扱う場合にケット \(|\psi\rangle\) を用いる。
   - 内積 \(\langle\phi|\psi\rangle\) は第1変数について共役線形、第2変数について線形とする。
   - \(\lVert\cdot\rVert\) は内積から定まるノルムとする。
   - 行列・線形写像の随伴を \(A^\dagger\) と表す。
5. 本文の対象外を簡潔に示す。詳細な一覧は方式設計書を参照させる。
